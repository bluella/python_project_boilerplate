Before starting work:
1. Read `concepts/INDEX.md` and open any concept files relevant to the area you're touching.

After making any change:
1. Review the code diff and check if it adheres to code style and guidelines of the project.
2. Review CLAUDE.md and relevant .claude/rules of the project and update them to be accurate given the changes.
3. If the change introduces, alters, or removes a domain concept, update `.claude/concepts/` accordingly (see `rules/concepts.md`).
