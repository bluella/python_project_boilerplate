# Glossary

The canonical spelling for every domain term in this project. **Before you use, introduce, or
rename a domain term, find it here and use the spelling in the "Term" column — never a synonym.**
The "Don't use" column lists spellings that mean the same thing and must not appear in new code,
docs, or concepts; if a term is renamed, its old spelling moves there (never drop it silently).

The "Where" column points at the implementation or the concept that defines the term in full.
